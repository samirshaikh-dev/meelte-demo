# meelTe Next.js Website

Marketing website for meelTe — a hyper-local community platform.

## What Is meelTe?

meelTe is both a company/brand and a hyper-local community platform. Keep those two meanings distinct:

- meelTe the company is the brand behind the product and needs a credible, clear digital presence.
- meelTe the platform helps people discover and connect with their local community, nearby opportunities, services, businesses, and relevant local activity.

Do not describe meelTe only as an app or only as a generic community feed. The website must explain the platform while also presenting the company as trustworthy and capable.

## Product Availability

The meelTe mobile app is currently available on Android. The web app is coming soon — never imply the full web app is already available.

## Stack

Next.js 16.4.3 (App Router), React 19.3.0, Tailwind CSS v4, npm.

## Getting Started

Run npm install then npm run dev. Open http://localhost:3000.
