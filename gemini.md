## Mandatory Pre-Implementation Protocol: ALWAYS Load & Use Agents Skills

> [!CAUTION]
> ### STRICT ENFORCEMENT: ZERO IMPLEMENTATION WITHOUT READING SKILLS
> Before proposing any changes, writing a single line of code, creating new files, or editing existing files, the AI **MUST ALWAYS load and read the applicable skill file(s) from `agents/skills/` using `view_file`**.

## Rules

1. **Skills First:** Always read relevant skill files in `agents/skills/` before proposing changes or writing code.
2. **Use the right package manager:** Use the package manager defined in `package.json` (`npm`).
3. **No Secret Commits:** Never expose or log `.env` values.
4. **Follow existing patterns:** Keep changes consistent with the current structure and style.
5. **Explain Your Work:** Clearly state what changed and why. Cite skills if applied.
